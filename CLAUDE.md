# Walle Agent SDK

Walle is an agent sdk that allows you to build your own agent. It has a light-weight core and plenty of plugins to support different features, such as memory, self-evolve, etc.

## Repo

Use pnpm monorepo to manage the codebase.

## Specs

This Repo is working on SDD(Spec-Driven Development). You should first read the specs to understand the design of Walle. And **after coding, you should update the specs to reflect the changes if any.**

[INDEX.md](./docs/INDEX.md) is the index of specs, you should first read it.

## Rules

- Use kebab-case for all file/folder names.
- Always ask user when the spec or requirement is not clear.
- Every complex task should be recorded in the [plans/](./plans/) folder. YOU CAN READ [README.md](./plans/README.md) to understand the structure of plans. These plans are long-term evidence of the development process. It's as important as the specs.
